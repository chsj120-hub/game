## 2. 보상 자동 공식

공통 형태: **값 = base × growth^(tier−1) × 배율들 × (1 ± jitter)**. Python(`tools/common.py`)과 GDScript(`Balance.gd`)가 같은 식을 씁니다.

### 2-1. 국가유산 기증(명성) · 매각(엽전)
```
유산 명성 = 100·2.15^(t−1) × 카테고리 × 은닉 1.25 × 신분격차 × (1 + 0.01·사 지식) × (1±0.08)
  └ 답사 명성(답사 즉시, 선택 무관) = 유산 명성 × 35%
  └ 기증 명성(관아·향교)            = 유산 명성 × 65% × 시설
매각 엽전 = 200·2.30^(t−1) × 카테고리 × 은닉 1.25 × 시설 × (1 + 0.03·상 지식) × (1±0.08)
신분격차 = 유산 등급 > 신분이면 1 + 0.10×차이 (윗등급 탐험 장려)
         유산 등급 < 신분이면 max(0.40, 1 − 0.15×차이) (하위 유산 반복 기증 억제)
```
| 등급 | 기증 명성 | 매각 엽전 | 엽전/명성 | 같은 등급 무기 가격 | 기증 최소 신분 |
|---|---|---|---|---|---|
| T1 | 100 | 200 | 2.00 | 60 | 1 |
| T2 | 215 | 460 | 2.14 | 180 | 1 |
| T3 | 462 | 1,058 | 2.29 | 540 | 2 |
| T4 | 994 | 2,433 | 2.45 | 1,620 | 3 |
| T5 | 2,137 | 5,597 | 2.62 | 4,860 | 4 |

- T1 100, T5 2,000~2,500(명성)과 T1 200, T5 5,000~6,000(엽전)이라는 원 기획 범위를 그대로 지킵니다.
- 카테고리 배율(명성/엽전): 전적 1.2/0.9, 금속 1.0/1.15, 도자·특산 1.0/1.25, 건축 0.9/0.8, 명승 0.8/0.6, 민속 0.9/0.9. "문헌은 명예, 도자·금속은 돈"이라는 성격 차이를 줍니다.
- 시설 배율: 향교는 전적·건축 기증 시 ×1.1. 암시장은 매각 ×1.25이지만 10% 확률로 적발되어 명성이 깎입니다(위험을 감수하는 선택지).
- 신분이 모자라 기증할 수 없는 경우: "관아가 감정을 거부"합니다. 이때는 보관하거나 매각할 수밖에 없어 초반의 '대박 유산'이 선택 고민으로 이어집니다.
- 권역 수집 보너스: 한 권역의 유산을 전부 답사하면(보상 선택과 무관하게) 그 권역 기증가 합계의 10%를 명성으로 받습니다.

### 2-2. 퀘스트 · 처치 · 기타
```
퀘스트 명성 = 120·1.9^(t−1) × 유형   퀘스트 엽전 = 100·2.1^(t−1) × 유형
유형(명성/엽전): 장비 1.0/0.6 · 탈것 1.2/0.5 · 동료 0.8/0.4 · 인스턴스 1.5/1.2 · 이벤트 1.3/1.0 · 메인 2.0/1.5 · 수배 0.4/0.6 · 무역 0.5/— · 공문 0.5/0.5
처치 명성 = 5·2.2^(t−1), 처치 엽전 = 8·2.2^(t−1), 보스는 명성 ×25 · 엽전 ×15
현상금 = 퀘스트(수배) × √처치수      무역 대금 = 기준가 × 수량 × 1.8
도시 투자비 = 800·1.6^단계 + 도 명성 요건(§3-4), 투자 명성 = 투자비 × 8%(전국 명성만·반복 원천)    승급 하사품 = 150·2.6^(L−2)냥

```

## 3. 명성 총량과 신분 곡선 (최대치 기준 재배분)

### 3-1. 유산 명성 = 답사 명성 + 기증 명성
유산 명성은 3택(사용·기증·매각)에 따라 0%~100%로 크게 흔들립니다. 그래서 **답사 명성(기본값의 35%)** 을 떼어, 보상 선택과 관계없이 답사하는 순간 줍니다. 기증하면 나머지 65%를 받습니다.
- 유산 명성 범위: 분리 전 0 ~ 195,174 → **분리 후 68,311 ~ 195,174**
- 효과: 매각형이 Rank 5에 닿는 시점이 콘텐츠의 56% → **37%** 로 당겨집니다(기증형 30%, 균형형 33%).
- 재미 장치는 모두 답사 명성에도 적용됩니다: 윗등급 선행 발견 보너스·하위 감쇠(신분 격차), 은닉 ×1.25, 사 지식 보너스.

### 3-3. 신분 임계 — "1/3을 찾으면 엔딩"
진행 몬테카를로 시뮬레이션(성향별 300명)으로 보정했습니다. 콘텐츠를 무작위 순서로 찾아가되, 신분+1 등급까지는 자유롭게, 그 위 등급은 가중치 0.2로 탐험합니다. 퀘스트는 등급−1 신분부터, 메인 N장과 동료 영입·승급(t등급)은 Rank N(t)부터 열립니다. 재미 장치(감정 거부 시 70% 보관·30% 매각, 매각의 35%는 암시장이며 적발 10%, 권역 전수 보너스)도 모두 넣었습니다. 그 결과로 **균형형 플레이어가 콘텐츠의 1/3을 찾았을 때(중앙값) Rank 5**가 되도록 맞췄습니다.

| 신분 | 동료 승급 반영 전 | **현재 임계** | 최대치 대비 | 기준치 대비 |
|---|---|---|---|---|
| 2 | 2,700 | **3,200** | 0.7% | 0.9% |
| 3 | 12,500 | **15,500** | 3.6% | 4.4% |
| 4 | 31,500 | **38,000** | 8.7% | 10.8% |
| 5 | 59,500 | **73,000** | 16.7% | 20.7% |

적합식: **Threshold(L) = 3,249·(L−1)^2.245** (곡률은 이전 설계를 유지). 승급 퀘스트가 명성을 더 공급하므로 같은 "1/3 → 엔딩" 체감을 유지하려고 임계가 약 23% 올랐습니다.

| 성향(기증/사용/매각) | Rank 3 도달 | Rank 5 도달(중앙값, p10~p90) |
|---|---|---|
| 기증형 60/20/20 | 10.6% | 29.1% (26.9~31.5) |
| 균형형 ⅓/⅓/⅓ | 12.6% | **33.4%** (31.0~35.8) |
| 매각형 15/25/60 | 14.1% | 36.9% (34.1~39.4) |

- "최대치의 1/3"을 그대로 임계로 쓰지 않은 이유: 플레이어는 낮은 등급(명성이 적은) 콘텐츠를 먼저 찾습니다. 그래서 명성 1/3을 모으려면 콘텐츠를 절반 넘게 찾아야 합니다. "1/3만 찾아도 엔딩"이라는 체감을 기준으로 삼으면 임계는 최대치의 16.7%가 됩니다.
- 엔딩: 메인 시나리오 N장은 신분 Rank N 이상에서만 진행할 수 있고, **5장 완료가 엔딩**입니다. 엔딩 뒤에도 남은 콘텐츠는 계속 이어집니다.

### 3-4. 도(道) 명성 — "2/3을 찾으면 도별 감영 5단계"

### 3-5. 엽전 여유 — 적용안: 감영 발전을 주 지출처로
수입 공식은 바꾸지 않았습니다. 대신 **도 수부(감영) 9곳의 발전 5단계를 필수 지출로 설계**하고, 투자한 만큼 도 전역에 혜택을 줍니다. 도시 발전에는 엽전과 도 명성이 **둘 다** 필요합니다(§3-4).

| 발전 대상 | 단계당 혜택 (`town_dev.benefits`) |
|---|---|
| 감영(도 수부) | 그 도 전역 매입가 −2%, 숙박비 −10%, 역마 삯 −8%, 객주 막사 +2칸. 5단계 '감영 중흥': 그 도에서 얻는 1회성 명성 +10% |
| 기타 대도시 28곳 | 그 도시만 매입 −3%, 매각 +2% (선택 과제) |

| 성향 | 수입 ÷ 필수 지출 (장비·탈것·비전서·일급·생활 + 감영 9곳 5단계 − 혜택 환급) | 참고: 감영 제외 | 기타 도시 28곳까지 전부 |
|---|---|---|---|
| 기증형 | **1.22배** | 2.23 | 0.49 |
| 균형형 | **1.50배** | 2.74 | 0.60 |
| 매각형 | **2.05배** | 3.77 | 0.82 |

- 필수 지출은 23.5만 냥입니다(생활·장비·일급 12.8만 + 감영 11.4만 − 혜택 환급 0.7만). 동료가 1~3등급에서 시작해 신분만큼만 승급하므로 일급(등급 곡선)이 이전 가정(신분+1 등급)보다 줄었습니다.
- 승급 퀘스트는 엽전 보상 없이 **명성 + 동료 성장**만 줍니다. 엽전까지 주면 균형형 비율이 1.73배로 올라 감영 싱크가 약해졌기 때문입니다(검토 후 제외).
- 기증형은 조금 팔아야 감영을 다 키우고, 매각형은 돈이 넉넉해도 도 명성이 모자라면 투자할 수 없습니다.
- 나머지 대도시 28곳(35만 냥)은 어느 성향도 다 채우지 못하는 후반 잉여 흡수처입니다.
- 미세 조정 창구는 `town_dev.cost_growth`(1.6) 하나입니다.

## 5. 흥미도 장치 요약 (모두 게임과 진행 시뮬에 반영)
- **답사 명성 35% 보장**: 무엇을 고르든 발견 자체가 보상입니다.
- **신분 격차**: 윗등급 유산을 먼저 찾으면 +10%/등급, 하위 유산을 늦게 기증하면 감쇠(최저 40%). 기증 창에 배율을 표시합니다.
- **관아 감정 거부**: 신분이 모자라면 기증이 막혀 보관하거나 암시장에 팔지 고민하게 됩니다.
- **암시장**: 매각가 ×1.25, 10% 확률 적발 시 명성 −30%.
- **권역 전수 답사 보너스**, 화첩 완성, 탁본 22첩 완성.
- **도 명성**: 도시를 키우려면 그 도를 실제로 탐험해야 합니다. 대시보드와 도감에 도별 진행이 표시됩니다.
- **메인 N장 = Rank N**: 신분 승급과 이야기 진행이 맞물립니다.
- **익숙한 길 ×2, 행군 중 소문**.
- 역사 이벤트 기한이 지나면 관군이 수습(감점 없음), 보스별 상성·저항 카운터.
- 동료 통합 전투: 한 턴에 여러 스킬을 이어 쓰되, 많이 쓸수록 다음 턴이 늦어지는 선택.

## 8. 동료 통합 전투 — AP 가산 방식
### 추천·적용 방식
| 규칙 | 값 (`battle.party_merge`) | 이유 |
|---|---|---|
| 전장 | 주인공 1명. 동료는 카드로 동행 | 요청대로 스킬·지식만 합산 |
| 스킬 | 동행 동료의 스킬이 주인공 목록에 합쳐짐(동료 이름 표시) | |
| **AP 상한** | 5 + **동료당 +1** (3인 = 8) | 스킬이 늘어난 만큼 한 턴에 쓸 수 있는 폭을 넓힘 |
| **AP 충전** | 턴당 2 + **동료당 +1** (3인 = 5) | 동료 수가 곧 행동량. 동료 영입의 가치가 체감됨 |
| 턴 구조 | **AP가 남는 동안 여러 스킬을 연속 사용**, [턴 종료] 또는 AP 소진 시 끝 | AP 가산이 실제 의미를 갖게 함 |
| 턴 비용 | 그 턴에 쓴 AP 총합으로 다음 게이지 재시작: 0:+300 1:+200 2:0 3:−150 4~5:−300 6:−380 7:−460 8:−540 | "몰아 쓰면 다음 턴이 늦다"는 선택 |
| 동료 1회 | 동료 한 명은 한 턴에 스킬 1회 | 한 동료 스킬 난타 방지 |
| 기본기 1회 | 1AP 기본기는 턴당 1회 | 1AP 연타가 스킬보다 효율적이 되는 것 방지 |
| 동료 숙련 보정 | 위력·회복·버프 × (1 + 0.06×(동료 등급−3) + 0.04×(★−1)) | 스탯 합산 없이 동료 등급·성장이 반영됨 |
| 쿨다운 | 사용 후 **자기 턴 N번** 재사용 불가 | 연속 행동에서도 쿨다운 의미 유지 |
| 게이지 부스트 스킬 | 자기 다음 턴 게이지에 가산(김홍도 등) | 대상 동료가 없어졌으므로 |

### 함께 조정한 전투 수치
주인공 혼자 모든 피격을 받게 되어 아래를 조정했습니다.
- **적 → 주인공 상성 배율 1.5 → 1.15** (`affinity_mult_enemy`). 아군 → 적은 1.5 그대로입니다.
- **일반 적(보스 제외) 공격 ×0.6 · HP ×0.8** (`normal_enemy_mult`). 여러 마리가 한 명만 노리는 것을 보정합니다.
- 보스 6종 스탯을 다시 튜닝했습니다(§4 표).
- 클러치 판정 지표를 "승리 시 전투 중 최저 HP < 40%"로 바꿨습니다(아슬아슬함 측정).

## 9. 동료 등급·승급 퀘스트 · 선단 불사환

### 시작 등급 (67명: DB-15 65명 + 게임 전용 남사고·신윤복)
점수 = 능력(DB-15 원래 등급 2~5) + 분류 가중(역사 인물 2 · 신화/설화 1.5 · 소설 1~1.2 · 직업 0) + 유명도(1.5 / 0.5). 점수순으로 3등분했습니다.

| 시작 등급 | 인원 | 예시 |
|---|---|---|
| 3등급 (신분 3에서 영입) | 22 | 이순신·정약용·허준·김정호·장영실·을지문덕·사명대사·원효·서산대사·홍길동·바리공주 |
| 2등급 (신분 2) | 23 | 박지원·황진이·전우치·이제마·심청·성춘향·이몽룡·흥부·허생·남사고 |
| 1등급 (신분 1) | 22 | 착호갑사·심마니·뱃사공·대장장이·보부상·주모·한지장이·숙향·장화·홍계월·신윤복 |

### 승급 퀘스트 (201건, 서사 맞춤 자동 설계 — `tools/db15/companions.py`)
- **트리거**: 주인공 신분 Rank ≥ t · 해당 동료 동행 · 대표 지식 ≥ t · **시작 장소(영입지)에 있을 때 수락**. 동선 첫 노드가 시작 장소입니다.
- **동선**: 동선 큐 규칙 그대로 적용합니다. 2등급은 같은 권역 2노드, 3~4등급은 인접 2~3권역 3노드, 5등급은 전국 3~5권역 4노드입니다. 제주는 뱃길로 이어진 권역을 인접으로 봅니다.
- **서사**: 동료 성향으로 경유지 유형을 고릅니다.

| 성향 | 경유지 유형 |
|---|---|
| 유교 | 서원·관아·진보 |
| 불교 | 명찰·석탑 |
| 선도 | 성황당·절경 |
| 바다 | 포구·침몰선 |
| 장인 | 가마터·장터 공방 |
| 의원 | 약방·온천 |

  단계 문구도 성향에 맞춰 붙입니다. 제목과 서사에는 대표 물품·대표 스킬명이 들어갑니다. 5등급의 마지막 장소는 역사적 무대로 고정했습니다(이순신 → 명량 울돌목, 정약용 → 수원화성, 김정호 → 백두산 천지 등 40명). 나머지는 성향에 맞는 고등급 유산 노드로 정합니다.
- **승급 효과**: 스킬 숙련 배율이 1등급 0.84에서 5등급 1.16까지 오릅니다(등급당 +8%). 위력·회복량·버프 수치에 모두 적용됩니다. 대표 지식도 +1이라 지식 합은 현재 등급과 같습니다(파티 합산 상한 10).
- **보상**: 명성 = 퀘스트 공식 × 0.5(`companion_promo`), 엽전 없음. 일급은 현재 등급 기준입니다.
- 게임: `CompanionSystem.tier_of / knowledge_of / next_promotion / promotion_lock / promote`, 퀘스트 메뉴에 자동 노출, 동료 메뉴에 현재 등급·숙련·지식·다음 승급 조건 표시.
- 시뮬레이터 가정: 동료는 신분까지 승급을 마친 상태입니다(Rank 3 클러치는 3등급, Rank 5는 5등급).

### 선단 불사환 — 부활 → 즉사 방지 버프
복용(1 AP)하면 **불사(不死)** 상태가 자기 턴 3회 동안 이어집니다. 이 동안에는 치명타를 맞아도 HP가 1에서 멈추고 더 줄지 않습니다. 동료 통합 전투에서는 주인공이 쓰러지면 바로 패배하므로 기존 부활(revive)은 쓸 기회가 없었습니다. 해로운 효과 해제(cleanse)로도 불사는 지워지지 않습니다. 구현은 `Combatant.take_damage`이고, 시뮬레이터 `C.take`가 같은 동작을 합니다.

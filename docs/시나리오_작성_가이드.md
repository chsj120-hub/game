# 시나리오 작성 가이드

**시나리오 1편 = JSON 파일 하나**입니다. `data_src/scenarios/`에 파일을 넣으면 시작 화면에 ★ 항목으로 나타납니다.
- 예시 1: `sc_jeju_mandeok.json` — 제주 김만덕 편 (튜토리얼 12단계)
- 예시 2: `sc_uiju_imsangok.json` — **작성 예시** 의주 만상 임상옥 편 (5장 + 짧은 안내 3단계 + 전용 이벤트 1)

## 1. 3단계로 추가하기
```bash
# ① 쓸 노드 찾기 (이름·권역으로 검색 → '@이름' 표기와 id, 시설, 유산 수)
python3 tools/scenario_tool.py nodes 의주
python3 tools/scenario_tool.py nodes 평안 남부 --type city
python3 tools/scenario_tool.py ids minigame      # enemy · item · instance · class 도 가능

# ② 틀 만들기 → data_src/scenarios/sc_my_story.json 을 열어 채우기
python3 tools/scenario_tool.py new sc_my_story 홍길동 cls_dosa @한양 경조

# ③ 검사 → 게임 데이터에 반영
python3 tools/scenario_tool.py check             # 동선 규칙·참조·장별 이동 거리/시간
python3 tools/run_pipeline.py --fast             # 약 17초 (전투 시뮬 생략)
```
엑셀로 쓰고 싶으면 장면(단계)마다 한 줄씩 적어 보내 주세요. 제가 이 형식으로 바꿔 드립니다.

## 2. 파일 구조
```jsonc
{
 "scenario": {                      // 시작 설정
  "id": "sc_uiju_imsangok",         // 'sc_' 로 시작, 파일 이름과 같게
  "name": "[예시] 의주 만상 임상옥 편", // 시작 화면 표시
  "hero_name": "임상옥",             // 대시보드·기록창 표시
  "class": "cls_merchant",          // cls_eosa(어사) · cls_merchant(상인) · cls_dosa(도사) — 능력치·스킬·지식
  "start_node": "@의주목",           // 시작 위치
  "money": 450, "items": {"food_rice_mal": 2},   // 직업 기본 지참물에 더해 줌
  "desc": "시작 화면 설명",
  "portrait": "res://assets/portraits/hero_imsangok.png",   // 선택: 초상(없으면 직업 기본)
  "costume": "merchant", "prompt_who": "…"                  // 선택: AI 초상 프롬프트(tools/prompt_lib.py COSTUME 키)
 },
 "main": {                          // 메인 시나리오(엔딩 = 마지막 장 완료)
  "name": "임상옥 — 압록강의 인삼 거상",
  "lore": "역사",                    // 도감 분류: 역사 · 설화 · 창작
  "era_note": "…",                  // 선택: 본편(1861)과 시대가 다를 때 시작 안내
  "chapters": [ {"chapter": 1, "tier": 1, "title": "만상의 점원", "stages": [ …단계… ]}, … ]
 },
 "tutorial": [ …안내 단계… ],        // 선택: [] 이면 안내 없음
 "events": [ …이 시나리오와 함께 추가할 이벤트… ]   // 선택: 20_events 형식(누구에게나 열림)
}
```
- **노드 표기:** `@이름`을 씁니다. 같은 이름이 여러 곳에 있으면 `@권역:이름`(예: `@평안 남부:순천`)으로 씁니다. `ND_…` id를 그대로 써도 됩니다.
- 이름이 틀리면 `check`가 비슷한 이름을 알려 줍니다.

## 3. 장(chapter) 규칙 — 게임 밸런스와 연결됨
| 장 등급(tier) | 열리는 신분 | 단계(노드) 수 | 권역 |
|---|---|---|---|
| 1 · 2 | Rank 1 · 2 | 2 | 한 권역 안 |
| 3 · 4 | Rank 3 · 4 | 3 | 이웃한 2~3권역 (뱃길 포함) |
| 5 | Rank 5 | 4~5 | 3~5권역 |

- 장 등급은 1→5 순서로 올라갑니다. 신분이 오르면 다음 장이 열리고, **5장 완료가 엔딩**입니다.
- 신분은 콘텐츠의 약 1/3을 찾으면 Rank 5가 되도록 자동 보정되므로, 시나리오를 따라가며 유산 답사·무역·동료를 함께 즐기게 됩니다.
- **보상은 자동**입니다(장 등급의 메인 퀘스트 공식). 명성과 엽전을 직접 적지 않습니다.
- 5장은 전국 여정이라 이동 시간이 깁니다. `check`가 장별 이동 거리(리)와 게임 시간(h)을 보여 주니, 너무 멀면 노드를 바꾸세요.

## 4. 단계(stage) 종류
| action | 필요한 칸 | 플레이 |
|---|---|---|
| `talk` | `text` | 장면 대사를 읽으면 진행 |
| `choice` | `text`, `choices[]`(2개 이상) | 선택. 효과는 `knowledge_xp`{유·불·선·사·농·공·상 경험치}, `money_mult`(이 장 엽전 보상 배율) |
| `minigame` | `minigame` (id) | 미니게임 성공 시 진행(실패하면 재도전) |
| `deliver` | `item`, `qty` | 아이템 납품 |
| `battle` | `waves` [[적 id…]…] | 웨이브 전투 승리 |
| `instance` | `instance` (id) | 탐색 연속전투(17 시트) |

지식 키: `yu` 유 · `bul` 불 · `seon` 선 · `sa` 사 · `nong` 농 · `gong` 공 · `sang` 상

## 5. 튜토리얼 단계
```json
{"title": "통군정으로", "text": "설명", "hint": "무엇을 누르면 되는지", "cond": {"type": "at_node", "node": "@의주 통군정"}}
```
| cond.type | 칸 | 넘어가는 때 |
|---|---|---|
| `ack` | — | [다음] 버튼 |
| `counter` | `key`, `n` | 행동 횟수: open_facilities · open_map · buy · sell · craft · unpack · heritage · battle_win · trade_accept · trade_done · save · event_stage · gather · camp |
| `at_node` | `node` | 그 노드에 도착 |
| `has_item` | `item`, `n` | 아이템 보유 |
| `visited` | `n` | 방문한 노드 수 |
| `event_progress` | `event`, `n` | 이벤트·메인 시나리오가 n단계 진행 |

## 6. 전용 이벤트 (선택)
`events[]`에 넣은 이벤트는 20 시트에 합쳐지며, 조건이 맞으면 **누구에게나** 열립니다(예: 책문 후시).
- 형식은 김만덕 편 이벤트나 `tools/content_expand.py`의 EVENTS와 같습니다.
- 칸: `trigger`{region, rank_min, solar_terms?}, `stages`, `deadline_days`, `fail_safe`, `codex`
- 동선 규칙은 장과 같습니다(이벤트 `tier`).

## 7. 작성 요령
- **역사 인물**은 실제 연대·사건을 따르고, 전해 오는 이야기는 "전하는 이야기에 따르면"처럼 구분해서 씁니다.
  - 예: 임상옥의 연경 인삼 불태우기 → 4장에서 선택으로
- 본편(1861)과 시대가 다르면 `era_note`로 알립니다.
- 선택지는 **한쪽은 지식(성장), 한쪽은 엽전(당장 이익)**처럼 성격이 다르게 만들면 고르는 재미가 생깁니다.
- 장면은 이미 있는 **유산·시설이 있는 노드**에 두면, 이야기 도중 답사·무역이 자연스럽게 이어집니다. `nodes` 결과의 "유산 n"과 "시설"을 보세요.
- 초상: `portrait` 경로를 적어 두면 `gen_asset_manifest`가 AI 프롬프트(`assets/prompts/portraits_hero.csv`)를 자동으로 만듭니다.

 대동여지도 어드벤처 — 무료 AI로 에셋 대량 제작하기 (초심자용 · 맥 미니 기준)
================================================================
처음부터 끝까지 이 순서대로 따라 하시면 됩니다.
  1부  준비 (한 번만 합니다)             약 1~2시간. 대부분 다운로드를 기다리는 시간입니다.
  2부  지도로 스타일 확정하기            약 2~5시간 (메모리 8GB는 더 걸립니다)
  3부  나머지 에셋 대량 생성             며칠에 걸쳐 밤마다 돌려 두면 됩니다.
  4부  문제 해결
  부록 GTX 1060 PC를 쓰려면(고급)

※ 명령어는 [ ] 안의 내용을 그대로 복사해 붙여 넣습니다. 대괄호는 빼고 붙여 넣으세요.
※ 프로그램 화면이나 메뉴 이름은 버전에 따라 조금 다를 수 있습니다.


----------------------------------------------------------------
 0. 어떤 컴퓨터를 쓸까? → 맥 미니 (이 가이드는 맥 미니 기준)
----------------------------------------------------------------
★ 먼저 내 맥 미니의 칩과 메모리를 확인합니다.
  화면 왼쪽 위 사과() 메뉴 → "이 Mac에 관하여"
    - 칩: "Apple M1" / "Apple M2" / "Apple M2 Pro" 중 하나가 보입니다.
    - 메모리: 8GB / 16GB / 24GB / 32GB
  ※ 2022년에 새로 나온 맥 미니 모델은 없습니다. 2022년에 사셨다면 대부분 M1(2020년 출시)이고,
    2023년 1월 출시 모델이면 M2입니다. 어느 쪽이든 이 가이드를 그대로 따르면 됩니다.

메모리에 따라 설정 묶음(프리셋)을 하나 고릅니다. 1-6에서 명령 한 줄로 적용합니다.

 메모리    프리셋    가능한 수준                                   속도(M1 기준, 추정)
 -------------------------------------------------------------------------------------------
 8GB       mini8     됩니다. 다만 메모리가 빠듯해 느립니다.         지도 1장 6~12분, 아이콘 1장 2~4분
                     해상도를 낮추고, 지도 입체(depth) 고정은 끕니다.
 16GB      mini16    무난합니다(추천).                             지도 1장 3~5분, 아이콘 1장 1~1.5분
 32GB 이상 standard  원래 해상도로 생성합니다.                     지도 1장 2~4분
 (M2는 M1보다 약 20~30% 빠릅니다.)

- 게임 규격은 어느 프리셋이든 똑같습니다(지도 3840×2160 등).
  작은 해상도로 그린 뒤 확대해서 맞추기 때문입니다.
- 8GB 모델에서 지켜 주세요.
  - 생성하는 동안에는 사파리·카카오톡 등 다른 앱을 모두 끕니다.
  - ComfyUI 화면 탭은 하나만 엽니다.
  - 아이콘(424장) 같은 큰 배치는 밤새 여러 번 나눠 돌립니다. 스크립트가 이어서 만들어 줍니다.
- 맥 미니는 모니터를 꺼도 계속 작동합니다. 다만 잠자기에 들어가면 멈추니, 1-7에서 잠자기를 막는 방법을 따라 하세요.
- GTX 1060 PC는 쓰지 않습니다.
  - PyTorch가 이 세대(Pascal) 그래픽카드 지원을 없애는 중이라, 최신 ComfyUI가 실행되지 않을 가능성이 큽니다.
    (출처: https://dev-discuss.pytorch.org/t/3128 , https://dev-discuss.pytorch.org/t/3432)
  - 굳이 보조로 쓰는 방법은 부록에 있습니다(고급).

필요한 저장 공간: 최소 40GB (모델 약 12GB + 프로그램 + 결과물)
  - 확인 방법: 사과 메뉴 → 시스템 설정 → 일반 → 저장 공간
  - 기본 용량(256GB)이 부족하면 외장 SSD에 ComfyUI를 설치해도 됩니다(1-3의 설치 위치를 외장 SSD로 지정).

 1부. 준비
================================================================

----------------------------------------------------------------
 1-1. 게임 파일을 맥 미니에 받기
----------------------------------------------------------------
1) 사파리에서 아래 주소를 엽니다. ZIP 파일이 바로 내려받아집니다.
   https://github.com/chsj120-hub/game/archive/refs/heads/daedong-adventure.zip
   (저장소가 비공개라면 먼저 사파리에서 github.com에 로그인해야 합니다)
2) "다운로드" 폴더에서 ZIP을 더블클릭해 압축을 풉니다.
3) 압축이 풀린 폴더(game-daedong-adventure)의 이름을 "game"으로 바꿉니다.
4) 그 폴더를 "문서"(Documents) 폴더로 옮깁니다.
   → 최종 위치: 문서/game   (이 안에 assets, tools, data 폴더가 보이면 성공입니다)

----------------------------------------------------------------
 1-2. 터미널 열고 파이썬 확인
----------------------------------------------------------------
1) ⌘(Command) + 스페이스를 누르고 "터미널"을 입력한 뒤 엔터를 누릅니다.
2) 아래 명령을 붙여 넣고 엔터를 누릅니다.
   [ python3 --version ]
   - "Python 3.x.x"가 보이면 됩니다.
   - "명령어 라인 개발자 도구를 설치하겠습니까?" 창이 뜨면 "설치"를 누릅니다. 약 5~10분 기다린 뒤 다시 입력합니다.
3) 게임 폴더로 이동합니다(터미널을 새로 열 때마다 이 명령부터 입력합니다).
   [ cd ~/Documents/game ]

※ 일괄 생성 스크립트는 추가로 설치할 것이 없습니다(파이썬 기본 기능만 씁니다).

----------------------------------------------------------------
 1-3. ComfyUI Desktop 설치 (무료 이미지 생성 프로그램)
----------------------------------------------------------------
1) https://www.comfy.org/download 에서 macOS(Apple Silicon)용을 받습니다.
2) 받은 .dmg를 열고, ComfyUI 아이콘을 "응용 프로그램" 폴더로 끌어다 놓습니다.
3) 응용 프로그램에서 ComfyUI를 실행합니다.
   - "확인되지 않은 개발자" 경고가 뜨면: 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "그래도 열기"를 누릅니다.
4) 처음 실행하면 설정 화면이 나옵니다.
   - GPU: Apple Metal (MPS)
   - 설치 위치: 기본값(예: 문서/ComfyUI)을 그대로 둡니다. ★ 이 위치를 꼭 기억하세요.
   - 나머지는 기본값으로 두고 설치합니다. 약 10~20분 걸립니다.
5) 노드(상자)들이 연결된 화면이 나오면 설치가 끝난 것입니다.
   - 이 창은 켜 둔 채로 작업합니다. 스크립트가 이 프로그램에 일을 맡기는 방식입니다.

----------------------------------------------------------------
 1-4. 모델 파일 3개 받아서 넣기
----------------------------------------------------------------
세 가지 모두 상업적 이용이 가능한 라이선스입니다.
설치 위치(예: 문서/ComfyUI) 안의 models 폴더에 넣습니다.

 ① 기본 그림 모델 (약 6.9GB) — SDXL 1.0 (CreativeML OpenRAIL++-M)
    https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0/blob/main/sd_xl_base_1.0.safetensors
    → 페이지의 "download" 버튼을 누릅니다.
    → 받은 파일을 models/checkpoints 폴더에 넣습니다.

 ② 구도 고정 모델 (약 2.5GB) — ControlNet Union SDXL (Apache-2.0)
    https://huggingface.co/xinsir/controlnet-union-sdxl-1.0/blob/main/diffusion_pytorch_model_promax.safetensors
    → 받은 파일의 이름을 controlnet-union-sdxl-promax.safetensors 로 바꿉니다.
    → models/controlnet 폴더에 넣습니다.

 ③ 확대 모델 (약 64MB) — Real-ESRGAN x4plus (BSD-3)
    https://github.com/xinntao/Real-ESRGAN/releases/download/v0.1.0/RealESRGAN_x4plus.pth
    → models/upscale_models 폴더에 넣습니다.
    ※ 인터넷에서 많이 추천하는 "4x-UltraSharp"는 비상업 라이선스라서 게임 판매용으로 쓰면 안 됩니다.

넣은 뒤에는 ComfyUI를 완전히 껐다가(⌘Q) 다시 켭니다.
※ 메모리 8GB 모델도 같은 파일을 씁니다. 더 작은 모델로 바꾸면 ControlNet(지도 구도 고정)을 쓸 수 없습니다.

----------------------------------------------------------------
 1-5. 연결 점검
----------------------------------------------------------------
ComfyUI를 켜 둔 상태에서 터미널에 입력합니다.
   [ cd ~/Documents/game ]
   [ python3 tools/comfy_batch.py --check ]

- 모든 줄이 ✓이고 마지막에 "준비 완료!"가 나오면 성공입니다.
- ✗가 보이면, 그 줄 아래 "폴더에 있는 파일" 목록을 봅니다.
  파일 이름이 다르면 아래처럼 실제 이름으로 맞춰 줍니다.
   [ python3 tools/comfy_batch.py --set ckpt=실제파일이름.safetensors ]
   [ python3 tools/comfy_batch.py --set controlnet=실제파일이름.safetensors ]
- "연결하지 못했습니다"가 나오면 4부 ①을 보세요.


----------------------------------------------------------------
 1-6. 내 맥 미니에 맞는 프리셋 적용 (중요)
----------------------------------------------------------------
1-5의 --check 결과 중 "추천 설정: mini16 → python3 …" 줄에 나온 명령을 그대로 입력합니다.
   메모리 8GB  → [ python3 tools/comfy_batch.py --preset mini8 ]
   메모리 16GB → [ python3 tools/comfy_batch.py --preset mini16 ]
다시 --check를 입력해 "(적용됨)"이 보이면 끝입니다.
프리셋이 바꾸는 값:
   - low_memory(작은 해상도로 생성 후 확대)
   - steps(단계 수)
   - map_depth_strength(지도 입체 고정, mini8은 0 = 끔)

----------------------------------------------------------------
 1-7. 잠자기 막기 (밤새 돌릴 때)
----------------------------------------------------------------
방법 A (권장): 생성 명령 앞에 caffeinate -i 를 붙입니다. 그 작업이 끝날 때까지 잠자기에 들어가지 않습니다.
   [ caffeinate -i python3 tools/comfy_batch.py icons ]
방법 B: 시스템 설정 → 에너지(또는 에너지 절약) → "디스플레이가 꺼져 있을 때 자동으로 잠자기 방지"를 켭니다.

 2부. 지도로 스타일 확정하기
================================================================
지도는 게임 속 지형 판정(마스크)과 1:1로 겹쳐야 합니다.
스크립트가 실제 지형으로 만든 밑그림을 자동으로 넣어 해안선과 산줄기를 고정합니다.
  - assets/maps/guides/map_nn_relief.png: 음영 밑그림 → 윤곽(canny)으로 고정
  - assets/maps/guides/map_nn_height.png: 고도 → 깊이(depth)로 고정
프롬프트 끝의 --ar 표기와 한글은 스크립트가 알아서 정리합니다.
(SDXL은 한글을 읽지 못하고 글자 얼룩을 그려 넣기 때문입니다.)

----------------------------------------------------------------
 2-1. 첫 시험: 전라 남부 지도 1장
----------------------------------------------------------------
   [ python3 tools/comfy_batch.py maps --ids MAP_08 --test 1 ]

- 결과 위치: 문서/game/assets/_drafts/maps/MAP_08_seed1861.png
  (시험 결과는 _drafts 폴더에만 저장되고, 게임 폴더에는 들어가지 않습니다)
- Finder에서 이 파일과 assets/maps/guides/map_08_layout.png를 나란히 열어 비교합니다.
  - 해안선과 섬 위치가 비슷하면 성공입니다.
  - 파일을 선택하고 스페이스바를 누르면 미리보기로 볼 수 있습니다.

----------------------------------------------------------------
 2-2. 시드 여러 개 비교하기
----------------------------------------------------------------
"시드"는 같은 설정에서 그림을 달라지게 하는 번호입니다.
   [ python3 tools/comfy_batch.py maps --ids MAP_08 --test 4 ]
→ 서로 다른 시드로 4장을 만듭니다. 파일 이름에 붙은 숫자가 시드입니다.
→ 걸리는 시간: mini16 약 15~20분, mini8 약 30~45분. 기다리는 동안 다른 앱은 켜지 마세요.
→ 마음에 드는 그림의 시드를 저장합니다.
   [ python3 tools/comfy_batch.py --set seed=그숫자 ]

----------------------------------------------------------------
 2-3. 느낌 조절하기 (설정값)
----------------------------------------------------------------
한 번에 하나씩만 바꾸고, 2-2 명령으로 다시 비교합니다.
지금 설정은 이렇게 봅니다.   [ python3 tools/comfy_batch.py --show ]

 설정 이름             기본값  무엇이 바뀌나                       예시
 ------------------------------------------------------------------------------
 cfg                   6.0     높을수록 프롬프트를 강하게 따름      5 ~ 8
 style_weight          1.15    수묵·한지 화풍의 세기                1.0 ~ 1.4
 map_edge_strength     0.8     해안선·산줄기를 밑그림에 붙이는 힘   0.6 ~ 1.0
 map_depth_strength    0.5     산의 높낮이 입체감(0이면 끔)         0 ~ 0.7   ※ mini8은 0(메모리 절약)
 canny_low/canny_high  0.15/0.45  윤곽을 얼마나 촘촘히 잡나(낮을수록 선이 많음)
 steps                 30      그리는 단계 수(높을수록 느리고 약간 정교해짐)  25 ~ 40

 예시) [ python3 tools/comfy_batch.py --set cfg=7 style_weight=1.3 ]

증상별 처방
- 해안선이 밑그림과 어긋남        → map_edge_strength 를 0.9~1.0으로 올립니다.
- 선만 보이고 그림 맛이 없음      → map_edge_strength 0.65, canny_high 0.6
- 서양 판타지 지도처럼 나옴       → style_weight 1.3
- 색이 너무 진하거나 탁함         → cfg 5

----------------------------------------------------------------
 2-4. (선택) 다른 모델 써 보기
----------------------------------------------------------------
기본 SDXL로 원하는 수묵 느낌이 약하면, Civitai(civitai.com)에서 "SDXL" 기반 수묵/일러스트 모델을 받아 비교합니다.
 - 모델 페이지에서 "Base Model: SDXL 1.0"인지 확인합니다. Pony나 Illustrious 계열은 제외합니다.
 - 라이선스에서 "Sell images"(이미지 판매)가 허용되는지 꼭 확인합니다.
 - models/checkpoints에 넣고 ComfyUI를 재시작한 뒤 이렇게 바꿉니다.
   [ python3 tools/comfy_batch.py --set ckpt=새모델.safetensors ]
 ※ 모델을 바꾸면 이미 만든 에셋과 화풍이 달라집니다. 반드시 대량 생성 전에 확정하세요.

================================================================
 3부. 나머지 에셋 대량 생성 (이 순서 추천)
================================================================
지도에서 확정한 모델과 설정을 그대로 씁니다. 화풍을 통일하기 위해서입니다.
배치 이름은 앞부분만 써도 됩니다(icons = icons_로 시작하는 파일 13개 전부).
각 배치는 먼저 --test 1 --limit 3 으로 3장만 확인한 뒤 본 생성을 돌립니다.

 예상 시간은 M1 기준 추정치입니다(mini16 / mini8).
 순서 배치              건수  mini16    mini8      명령
 ------------------------------------------------------------------------------------------
 ①  parallax           51    1시간     2~3시간    [ caffeinate -i python3 tools/comfy_batch.py parallax ]
 ②  battle_bg          17    20분      1시간      [ caffeinate -i python3 tools/comfy_batch.py battle_bg ]
 ③  portraits (3종)    91    2~3시간   5~7시간    [ caffeinate -i python3 tools/comfy_batch.py portraits ]
 ④  icons (13종)      424    7~10시간  15~25시간  [ caffeinate -i python3 tools/comfy_batch.py icons ]
 ⑤  markers            30    40분      1.5시간    [ caffeinate -i python3 tools/comfy_batch.py markers ]
 ⑥  minigames          24    40분      1.5시간    [ caffeinate -i python3 tools/comfy_batch.py minigames ]
 한 번에 전부(스프라이트 제외):                    [ caffeinate -i python3 tools/comfy_batch.py all ]

================================================================
 4부. 문제 해결
================================================================
① "ComfyUI 에 연결하지 못했습니다"
   - ComfyUI 앱이 켜져 있는지 확인합니다.
   - 주소가 다를 때: ComfyUI 화면 설정(톱니바퀴) → Server-Config에서 포트 번호를 확인하고 이렇게 맞춥니다.
     [ python3 tools/comfy_batch.py --set server=http://127.0.0.1:포트번호 ]
② "작업을 거부했습니다 … ckpt_name / control_net_name / model_name"
   → 모델 파일 이름이 설정과 다릅니다. 1-5의 --check로 실제 이름을 보고 --set으로 맞춥니다.
③ 새까만 이미지나 회색 노이즈만 나옴
   → ComfyUI 설정 → Server-Config에서 VAE 정밀도(VAE precision)를 fp32로 바꾸고 재시작합니다.
④ 메모리 부족, 극도로 느림, 맥이 멈춘 듯함 (특히 8GB)
   → 다른 앱을 모두 끄고, 한 단계 가벼운 프리셋으로 바꿉니다.
     [ python3 tools/comfy_batch.py --preset mini8 ]
   → 그래도 지도에서 멈추면 확대 모델을 끕니다(단순 확대로 대체되어 조금 흐려집니다).
     [ python3 tools/comfy_batch.py --set upscaler= ]
   → 활동 모니터(응용 프로그램 → 유틸리티) → "메모리" 탭에서 "메모리 압력"이 빨간색이면 메모리가 부족한 상태입니다.
⑤ 그림 안에 글자가 들어감 → 다시 생성하거나, cfg를 낮추거나, 시드를 바꿉니다.
⑥ 중국·일본풍이 섞임 → style_weight를 1.3으로 올립니다. 그래도 섞이면 수묵 계열 SDXL 모델로 바꿉니다(2-4).
⑦ 중간에 끊김 → 같은 명령을 다시 실행하면 이미 만든 파일은 건너뛰고 이어서 만듭니다.
⑧ 어떤 명령을 쓸지 모르겠음 → [ python3 tools/comfy_batch.py --help ]
   실제로 만들지 않고 할 일만 미리 보기 → 명령 끝에 --dry-run 을 붙입니다.


================================================================
 부록. GTX 1060 PC를 보조로 쓰려면 (고급, 선택)
================================================================
- 최신 ComfyUI Desktop/Portable은 GTX 1060(Pascal)을 지원하지 않는 PyTorch를 씁니다.
  - 쓰려면 ComfyUI를 직접 설치하고, 구버전 PyTorch(CUDA 12.6 빌드, 2.14 이하)를 지정해야 합니다.
  - 이 경우 최신 ComfyUI와 호환되지 않을 수 있습니다. 초심자에게는 권하지 않습니다.
- 굳이 쓴다면 아이콘처럼 ControlNet이 필요 없는 배치만 맡깁니다.
  1) 1060 PC에서 ComfyUI를 --listen 옵션으로 실행합니다.
  2) PC에서도 같은 모델과 같은 설정을 씁니다(--preset mini8과 같은 값). 그래야 화풍이 같게 나옵니다.
  3) 맥 미니와 서로 다른 배치를 나눠 돌립니다.
     예) 맥 미니: portraits / PC: icons_weapon icons_armor …
  4) 맥 미니 터미널에서 PC로 일을 보낼 수도 있습니다.
     --set server=http://PC의IP:8188   (끝나면 --set server=auto 로 되돌립니다)

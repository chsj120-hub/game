## A경로: 구글 AI 스튜디오 (브라우저, 무설치)

### A-1. 접속 및 준비 (5분)

1. **브라우저에서 [aistudio.google.com](https://aistudio.google.com) 으로 이동**합니다.
2. 구글 계정으로 로그인합니다 (구글 계정이 있으면 누구나 무료로 사용할 수 있습니다).
3. 왼쪽 메뉴에서 **"새 프롬프트 만들기"** 또는 **"Try Gemini 2.5 Flash"** 같은 버튼을 클릭합니다.
4. 화면 오른쪽 "모델 선택" 드롭다운에서 **`gemini-2.5-flash`** (또는 최신 Flash 계열)를 선택합니다.

> **이미지 생성 방법:** 텍스트 채팅창에 "이미지를 생성해 줘" 형식으로 입력하거나, 영어 프롬프트를 그대로 붙여 넣으면 됩니다. 2025년 기준 Gemini Flash 계열 모델이 이미지 생성을 지원합니다. 모델 목록에 이미지 아이콘(🖼️)이 붙어 있는 것을 선택하세요.

> **무료 한도:** Google AI Studio에서의 사용은 무료입니다(분당 요청 제한 있음, 개인 테스트 용도로는 충분합니다).

### A-2. 프롬프트 CSV 열기

```
assets/prompts/
```

Finder에서 이 폴더를 열면 CSV 파일들이 있습니다. 스프레드시트(Numbers 또는 엑셀)로 열어 확인합니다.

- **`prompt` 열** = AI에게 줄 영어 설명 (이미 만들어져 있습니다)
- **`name_kr` 열** = 한국어 이름 (무엇을 만드는지 확인용)
- **`path` 열** = 만든 파일을 저장할 경로

### A-3. 대화 배경 만들기 (scenes.csv, 15장)

대화 화면의 배경 그림입니다. 장면 분위기가 가장 중요합니다.

**방법:**
1. `scenes.csv`를 Numbers/엑셀로 엽니다.
2. `scene_city`의 `prompt` 값을 복사합니다:
   ```
   a walled Joseon provincial town with a government office gate and market street, Joseon 1861, Joseon-era Korean ink-and-wash painting (sumukchaesaek) on aged hanji mulberry paper, muted mineral pigments (malachite green, azurite blue, ochre, cinnabar red, ink black), confident brush strokes with dry-brush texture, soft paper grain, restrained palette, in the manner of Kim Hong-do and Jeong Seon, visual-novel background, eye-level wide establishing shot, empty of people, lower quarter kept calm for a dialogue box, 16:9 --ar 16:9 --style raw
   ```
3. AI 스튜디오 채팅창에 이 프롬프트를 그대로 붙여 넣고 전송합니다.
4. 생성된 이미지 위에 마우스를 올려 **다운로드** 버튼을 클릭합니다.
5. 파일명을 `path` 열에 적힌 값 그대로 바꿉니다(예: `scene_city.png`).
6. `assets/scenes/` 폴더에 저장합니다.

> **팁:** 프롬프트 맨 앞에 "Create an image:" 또는 "Generate:" 를 붙이면 응답이 더 빨리 이미지로 나옵니다.

> **해상도 조절:** AI 스튜디오는 보통 1024×1024 정도로 생성합니다. 생성 후 **Preview에서 원하는 비율로 내보내기**를 선택하거나, macOS 미리보기 앱으로 열어 `도구 → 크기 조절`에서 1920×1080으로 키웁니다(AI가 만든 그림은 품질 손실이 적습니다).

**15장 전체를 빠르게 만드는 방법:**

AI 스튜디오 채팅에서는 이렇게 한 번에 여러 장을 요청할 수 있습니다:

1. scene_city: a walled Joseon provincial town with a government office gate and market street, Joseon 1861
2. scene_town: a small Joseon village with thatched houses and a big zelkova tree
3. scene_station: a Joseon post-horse relay station with stables
4. scene_temple: a Korean Buddhist mountain temple courtyard with a stone pagoda
5. scene_spring: a Joseon hot-spring inn with steam rising
6. scene_fort: a Joseon mountain fortress wall and gate tower
7. scene_beacon: a stone beacon-fire mound on a ridge
8. scene_stupa: an old stone pagoda standing in a temple ruin
9. scene_tomb: a royal burial mound with stone guardian statues
10. scene_scenic: a famous Korean scenic landscape of cliffs and pines

여러 장을 한 번에 요청하면 순서대로 생성됩니다. 마음에 들지 않는 것만 "3번 다시 만들어 줘"처럼 재요청합니다.

지도는 이 게임에서 가장 중요한 에셋입니다. 구글 AI 스튜디오로 먼저 화풍을 확정하는 것을 권장합니다.

> **지도 주의사항:** AI가 만든 지도에 한글이나 숫자가 임의로 들어갈 수 있습니다. Photoshop 또는 Pixelmator Pro로 지우거나, 프롬프트에 **"No text, no labels, no numbers, no letters"** 를 추가합니다.

> **크기:** 게임 규격은 3840×2160이지만 AI 스튜디오에서 이 해상도로 직접 나오지는 않습니다. 생성 후 macOS 미리보기에서 크기 조절합니다(`도구 → 크기 조절 → 3840 × 2160`). 지형 형태가 바뀌는 것은 나중에 B경로(ControlNet)로 교체할 수 있습니다.

## B경로: Comfy Desktop (맥북에서 무제한 로컬 생성)

> 대량 아이콘(1,000장+) 또는 지도에서 해안선·산줄기 위치를 정확히 맞춰야 할 때 씁니다.  
> 처음 설치에 30~60분 걸리고, 모델 다운로드에 약 7~10GB 공간이 필요합니다.

### B-1. Comfy Desktop 설치 (2025년 최신 방법)

기존 가이드의 "터미널에서 명령어 입력" 방식 대신, **공식 앱을 설치**합니다. 훨씬 간단합니다.

1. **[comfy.org/download](https://www.comfy.org/download)** 를 사파리로 엽니다.
2. **"Download for Mac"** 버튼을 클릭합니다 (Apple Silicon 전용 `.dmg` 파일이 내려받아집니다).
3. 내려받은 `.dmg`를 더블클릭 → ComfyUI 아이콘을 Applications(응용 프로그램) 폴더로 드래그합니다.
4. Launchpad 또는 Applications 폴더에서 **ComfyUI**를 실행합니다.
   - "확인되지 않은 개발자" 경고가 뜨면: `시스템 설정 → 개인정보 보호 및 보안 → 아무튼 열기`를 클릭합니다.
5. 처음 실행 시 Python 환경을 자동으로 설치합니다(인터넷 연결 필요, 약 5~10분).
6. 설치가 끝나면 **브라우저가 자동으로 열리며 ComfyUI 화면이 보입니다.**

> **요구 사항:** macOS Ventura(13.0) 이상, Apple Silicon(M1/M2/M3 이상), RAM 8GB 이상(16GB 권장).  
> 맥북 에어 8코어 16GB는 완전히 호환됩니다.

### B-2. 첫 화면 이해하기 (노드 화면)

ComfyUI는 **레고 블록처럼 기능을 연결하는 화면**입니다. 처음에는 복잡해 보이지만 핵심은 세 줄입니다.

```
[모델 불러오기] → [프롬프트 입력] → [이미지 저장]
```

화면을 보면 이미 여러 박스(노드)가 연결되어 있습니다. 지금은 이것을 건드리지 말고, **모델을 먼저 받아 연결**하는 것에만 집중합니다.

### B-3. 모델 받기 (중요)

ComfyUI는 프로그램이고, **모델**이 실제로 그림을 그립니다. 이 게임에는 SDXL 모델이 필요합니다.

**방법 1: ComfyUI Manager로 받기 (가장 쉬움)**

1. ComfyUI 화면 오른쪽 위에 **Manager** 버튼이 있습니다 (없으면 메뉴에서 찾아보세요).
2. **Manager → Install Models** 를 클릭합니다.
3. 검색창에 **`sdxl_vae`** 를 입력합니다 → 결과에서 "SDXL VAE" 항목을 찾아 **Install**을 클릭합니다.
4. 검색창에 **`sd_xl_base`** 를 입력합니다 → "SDXL 1.0 base" 를 찾아 **Install**을 클릭합니다.
   - 약 6.5GB를 내려받습니다. Wi-Fi 속도에 따라 10~30분이 걸립니다.

**방법 2: Hugging Face에서 직접 받기**

1. 사파리에서 `huggingface.co/stabilityai/stable-diffusion-xl-base-1.0/resolve/main/sd_xl_base_1.0.safetensors` 를 직접 열어 다운로드합니다.
2. 내려받은 파일을 아래 폴더로 이동합니다:
   ```
   ~/Library/Application Support/ComfyUI/models/checkpoints/
   ```
   Finder에서 `이동 → 폴더로 이동`(`⇧⌘G`)에 위 경로를 붙여 넣으면 찾을 수 있습니다.
3. ComfyUI 화면에서 **메뉴 → Refresh Models**를 클릭합니다.

### B-4. 기본 워크플로우 실행하기

1. ComfyUI 화면에서 **Examples** 버튼(또는 `Load → examples/text_to_image_sdxl`)을 클릭합니다.
2. 기본 SDXL 워크플로우가 화면에 펼쳐집니다.
3. **"CLIP Text Encode (Prompt)"** 박스(초록색 테두리)를 찾아 프롬프트를 입력합니다:
   ```
   a walled Joseon provincial town with a government office gate, Korean ink-and-wash painting on hanji paper, sumukchaesaek style, no people, muted colors
   ```
4. 부정 프롬프트(빨간색 테두리 박스)에는 다음을 입력합니다:
   ```
   people, characters, text, labels, signature, watermark, low quality, blurry
   ```
5. **"Queue Prompt"** 버튼(오른쪽 위, 파란색)을 클릭합니다.
6. 잠시 기다리면 오른쪽 아래에 결과 이미지가 나타납니다.

> **맥북 에어 16GB 속도:** SDXL 기준 1장에 약 1~3분입니다. 메모리 부족 오류가 나면 B-5를 먼저 하세요.

### B-5. 맥북 에어에 맞는 설정 (16GB 최적화)

ComfyUI 화면 위쪽 메뉴에서 **Settings(설정)** 을 엽니다.

| 설정 항목 | 권장값 | 이유 |
|---|---|---|
| `VAE precision` | `fp16` | 메모리 절약 |
| `Use CPU for VAE` | 끔 | Mac GPU(MPS)가 더 빠름 |
| `Preview method` | `NNLatent` | 중간 미리보기 표시 |
| `Max resolution (width × height)` | 1536 × 1536 이하 | 메모리 한계 |

WorkFlow 노드에서 `KSampler` 박스를 찾아 다음 값으로 바꿉니다:
- `steps`: 25~30 (기본 20보다 높이면 품질 향상)
- `cfg`: 7.0
- `sampler_name`: `euler` 또는 `dpmpp_2m`
- `scheduler`: `karras`

### B-6. 이 게임 전용 워크플로우 불러오기

기존 가이드(`AI_에셋_제작_가이드.txt`)에 설명된 `tools/comfy_batch.py` 스크립트가 여전히 동작합니다. 단, 이제는 **터미널 대신 ComfyUI 화면에서 직접** 해도 됩니다.

**터미널에서 일괄 생성:**
```bash
cd ~/Documents/game
caffeinate -i python3 tools/comfy_batch.py scenes          # 대화 배경 15장
caffeinate -i python3 tools/comfy_batch.py portraits_npc   # NPC 초상 10장
caffeinate -i python3 tools/comfy_batch.py portraits_companion  # 동료 초상 67장
```

`caffeinate -i` 를 앞에 붙이면 맥이 잠자기에 들어가지 않습니다.  
결과는 `assets/` 안의 해당 폴더에 자동으로 저장됩니다.

> **ComfyUI 서버가 먼저 켜져 있어야 합니다.** ComfyUI 앱을 실행해 브라우저에 화면이 뜬 상태에서 터미널 명령을 실행합니다.

### B-7. ControlNet으로 지도 해안선·산줄기 고정하기 (고급)

A경로에서 만든 지도와 달리 이 방법은 실제 한반도 지형 데이터를 바탕으로 해안선과 산줄기를 정확히 맞춥니다. 먼저 `tools/gen_terrain.py --jobs 4`로 밑그림을 만들어야 합니다 (약 10~20분).

**ControlNet 모델 받기:**
1. Manager → Install Models → 검색창에 `controlnet sdxl` 입력
2. **"SDXL ControlNet Union"** 을 찾아 Install (약 2GB)

**워크플로우:**
1. ComfyUI Manager → **Install Custom Nodes** → "ComfyUI_Comfy_Essentials" 또는 "ControlNet" 관련 노드를 설치합니다.
2. 화면 빈 공간 우클릭 → "Add Node" → "ControlNet" → "Apply ControlNet" 박스를 추가합니다.
3. `assets/maps/guides/map_01_relief.png` (밑그림)를 "Load Image" 노드에 연결합니다.
4. ControlNet type을 "canny"로 설정합니다.
5. strength를 0.7~0.85로 맞춥니다.

> 자세한 ControlNet 연결 방법은 기존 가이드(`AI_에셋_제작_가이드.txt` 2부)를 참고하세요.

## 문제 해결

| 증상 | 해결 |
|---|---|
| AI 스튜디오에서 이미지가 나오지 않고 텍스트만 나온다 | "이미지를 생성해 줘" 라고 명확히 요청하거나, 이미지 생성 지원 모델(Flash Image 계열)로 변경 |
| AI 스튜디오 이미지에 한글/숫자가 들어 있다 | 프롬프트에 "No text, no labels, no letters" 추가 |
| AI 스튜디오 이미지 해상도가 낮다 | macOS 미리보기 → `도구 → 크기 조절`로 확대 |
| ComfyUI 앱이 "확인되지 않은 개발자" 오류 | `시스템 설정 → 개인정보 보호 및 보안 → 아무튼 열기` |
| ComfyUI에서 빨간 오류 박스가 보인다 | Manager → "Install Missing Custom Nodes" 클릭 |
| ComfyUI 생성이 시작됐다가 바로 멈춤 | VAE precision을 fp16으로 변경 / 다른 앱 모두 종료 |
| 메모리 부족(Out of Memory) 오류 | 해상도를 1024×1024로 낮춤 / steps를 20으로 줄임 |
| 그림 화풍이 맞지 않는다 | 프롬프트의 `sumukchaesaek` 등 화풍 키워드를 유지했는지 확인 |
| 동일한 캐릭터가 생성마다 다르게 나온다 | seed 값을 고정하거나, AI 스튜디오에서 한 대화 세션 안에서 계속 수정 |

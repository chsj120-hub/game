- 03 특산물 32종(구매 21 + 제작 11)
- 04 식량 15종, 05 재료 26종, 10 약초 19종

## 0. 점검에서 나온 문제 (개편과 함께 고치길 권장)

| # | 문제 | 근거 |
|---|---|---|
| 1 | **곡물 단위가 맞지 않음** | 곡물은 교역용 "한 섬"(무게 20, 약 50냥) 단위인데, 국밥 한 그릇에 백미 1섬을 통째로 씀. 건량(6냥, 포만 30)이 훨씬 효율적이라 1등급 요리를 만들 이유가 없음. `ration: 10` 필드는 쓰이지 않음 |
| 2 | **요리 재료 고증 오류** | 빈대떡 = 조 + 꿩(녹두여야 함), 구절판 = 조 + 꿩, 전복초 = 굴비(전복이어야 함), 대하찜 = 굴비(새우), 타락죽 = 백미만(타락 = 우유) |
| 3 | **같은 물건이 두 줄로 따로 존재** | 개성 인삼(특산 2등급, 60냥) vs 인삼(약초 3등급, 120냥). 등급이 거꾸로임. 보은 대추(특산) vs 대추(약초). 북관 명태 vs 인제 황태는 서로 무관한 항목으로 되어 있음 |
| 4 | **쓰이지 않는 재료** | 도토리·칡뿌리·송기, 산토끼·반달곰·백록 고기, 주석 |
| 5 | **무역 공백 권역** | 경상 남부(MAP_10)는 살 수 있는 특산품이 0개. 황해 남부·평안·제주는 3~4등급 특산품만 있어서 초반에는 무역을 할 수 없음 |
| 6 | **경제 시뮬에 자유 무역이 빠져 있음** | `economy_sim.py`는 무역 **퀘스트** 수입만 계산함. 상위 무역품을 넣기 전에 자유 매매 수익 모델을 먼저 추가해야 함 |
| 7 | **DB-15 원본 미편입** | 식량 105종(지역 곡물 34·구황 34·수렵 37)과 생필품·식자재 70종 중 대부분이 게임에 들어오지 않음. 식자재·재료 후보로 쓸 수 있음 |

## 2. 공용 재료군 (애매한 1등급 재료를 묶어서 쓰기)

레시피 재료를 특정 품목 대신 **재료군**으로 적을 수 있게 합니다.
```json
{"group": "grain", "qty": 1}
```
재료군에 속한 품목이면 어느 것이든 씁니다.

| 재료군 | 들어가는 품목 | 쓰는 곳 |
|---|---|---|
| `grain` 곡물 | 백미·보리·조 (DB-15 메밀가루·지역 곡물 편입 가능) | 1~2등급 서민 요리의 "밥·곡물" |
| `grain_gu` 구황 | 도토리·칡뿌리·송기 (+ DB-15 감자·고구마·토란) | 수제비 대체, 구황 요리 신설 시 |
| `meat_game` 수렵육 | 산토끼(T1)·꿩(T2)·멧돼지(T3)·곰(T4)·백록(T5) | 1~2등급 고기 요리 |
| `fish_dried` 건어 | 북관 명태·인제 황태 (+ 멸치) | 어만두 등 |
| `fiber` 섬유 | 삼베·무명 → 명주실 → (금사) | 포획구·행장 수선·모작 |
| `jujube` 대추 | 약초 대추 = 보은 대추(특산) | 쌍화탕·약식·갈비찜 |
| `ginseng` 인삼 | 약초 인삼 = 개성 인삼 → 개성 홍삼 | 십전대보탕·신선로 등 |

**어디까지 묶을지 (추천)**
- **묶는 것:** 1~2등급 서민 요리의 곡물·고기
  - 국밥·주먹밥·콩나물국밥·수제비·타락죽·약식의 곡물
  - 빈대떡·떡국의 고기
- **묶지 않는 것:** 대표 요리의 고유 재료. 요리 정체성과 고증을 지키기 위해서입니다.
  - 전주 비빔밥·떡국·떡볶이의 백미, 평양 냉면의 메밀, 신선로의 재료
- **한방약:** 약재는 종류 자체가 효능이라 묶지 않습니다. 예외는 대추·인삼처럼 **같은 물건이 두 줄로 있는 경우**뿐입니다.
- **점토:** 백토와 청자토는 서로 대체하지 않습니다(백자와 청자는 흙이 다름).

**곡물 단위 개편 (#1 해결, 재료군의 전제 조건)**
- 조리용 "한 말"(1/10섬, 무게 2) 단위를 새로 만듭니다. 주막과 장터에서 팝니다.
- 인벤토리에 "섬 풀기"(1섬 → 10말)를 넣습니다. 비어 있던 `ration: 10` 필드를 여기에 씁니다.
- 레시피는 말 단위로 소모합니다. 섬은 교역품으로만 남습니다.

## 3. 상위 등급 재료로 대신 쓰기

**규칙**
- 같은 사슬(`line`)에 속한 **같은 등급 이상** 재료가 1:1로 하위 재료를 대신합니다.
- 소모 순서
  1. 정확히 그 품목
  2. 한 등급 위, 두 등급 위… 순서
  3. 같은 품목끼리는 신선도가 낮은 것(곧 상할 것)부터
- 공(工) 지식의 재료 감소는 먼저 개수에 적용한 뒤 대체를 계산합니다.

**재료 사슬 (05·04·03 공통)**

| 사슬 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 철 | 무쇠 | — | 정련 사철괴* | — | 운철🔒 |
| 동 | — | 구리 · 주석 | 황동* | — | — |
| 섬유 | 삼베 · 무명 | 명주실 | — | 금사* | — |
| 가죽 | 소가죽 | 산노루 가죽* | — | 표범 모피* | 호랑이 가죽*🔒 |
| 목재 | 느티나무 판재 | — | — | 벽조목* | — |
| 종이 | 닥나무 껍질 → 전주 한지 사슬(가공품 대체) | | | | |
| 수렵육 | 산토끼 | 꿩 | 멧돼지 | 반달곰 | 백록🔒 |
| 무역품 | 1장의 모든 사슬(예: 한지 상품이 한지를 대신함) | | | | |

\* = DB-15 원본에서 편입할 재료(약 8종). 🔒 = 희귀 재료로, **자동 대체에서 제외**합니다.

**낭비 방지 장치**
- 설정에 "상위 재료 대체"를 둡니다: 끔 / **확인(기본)** / 자동
  - "확인"일 때는 두 등급 이상 차이 나는 대체만 확인창을 띄웁니다.
  - 예: "무쇠 10 중 4개를 정련 사철괴로 대신합니다 — 제작할까요?"
- 🔒 희귀 재료(운철·호랑이 가죽·백록·산삼 등 `no_substitute`)는 레시피가 직접 요구할 때만 씁니다.
- 대체해도 품질이나 수치 보너스는 없습니다(1차 버전). 편의 기능일 뿐이라, 상위 재료가 더 비싸서 이득을 노리는 악용이 생기지 않습니다.
- 레시피 카드에 미리 보여 줍니다: `무쇠 ×10 (보유 6 + 정련 사철괴 4 대체)`

## 결정해 주실 것
1. 등급 이름: 일반 형식(상품/진상품)만 쓸지, 확인된 실제 명칭(세모시·오가재비·방짜)을 섞을지
2. 상위 대체 기본값: 확인(추천) / 자동 / 끔
3. 곡물 "말" 단위 개편을 포함할지 (재료군을 쓰려면 사실상 필요)
4. 요리 고증 수정(녹두·전복·새우·우유 재료 추가)을 포함할지
5. 공백 권역 신규 특산품 후보를 넣을지, 그리고 DB-15 재료 약 8종을 편입할지

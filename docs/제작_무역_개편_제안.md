# 제작·무역 개편 — 반영 내역과 추천

- 적용 도구: `tools/craft_trade_update.py`. 여러 번 실행해도 결과가 같고, 파이프라인에서 `build_world` 다음에 실행합니다.
- 수익 모델: `tools/trade_sim.py`
- 검증: `validate_data` · `balance_sim` · `db15/balance_check` 모두 PASS. 신분 임계와 엽전 비율(1.22/1.50/2.05)도 그대로입니다.

## 1. 반영 내역

### 1-1. 곡물 '말' 단위 · 1등급 요리 폐지
- **말 단위 신설:** 백미·보리·조 "한 말"(무게 2)
  - 값: 섬 시세 × 0.1 × 1.1(소매). 장터·5일장에서 팝니다.
  - 제작 탭에 **섬 풀기**(1섬 → 10말)가 생겼습니다. 비전서 없이 쓸 수 있고, 섬을 가지고 있을 때만 보입니다.
- **1등급 요리 폐지:** 국밥·콩나물국밥·주먹밥·수제비를 **2등급**으로 올리고 포만감도 올렸습니다(40~56).
  - 이제 모든 요리는 2~5등급입니다. 검증기가 1등급 요리가 생기면 오류를 냅니다.

### 1-2. 요리 재료 고증 수정
| 요리 | 변경 전 | 변경 후 |
|---|---|---|

| 설렁탕 | 백미 + 멧돼지 | **쇠고기** ×2 + 곡물 + 소금 |
| 갈비찜 | 멧돼지 + 대추 | **쇠고기** ×2 + 대추 + 장 |
| 장터 국밥 | 백미 1섬 + 소금 | 곡물 1말 + **쇠고기** + **장** |
| 콩나물국밥 | 백미 1섬 | 곡물 + **콩나물** + 장 |
| 전주 비빔밥 | 백미 + 멧돼지 + 당귀 | 백미 + 쇠고기(육회) + 콩나물 + 장 |
| 구절판 | 조 + 꿩 | **의주 진말**(밀전병) + 쇠고기 + 콩나물 |
| 전복초 | 영광 굴비 + 소금 | **제주 전복** ×2 + 장 + **잣**(잣가루) |

| 수제비 | 메밀 | 가루(진말·메밀) + 장 |

떡국(꿩 육수)과 평양 냉면(메밀 + 꿩 육수)은 원래 고증이 맞아서 그대로 두었습니다.

### 1-4. 같은 물건 정리
- **인삼**
  - 약초 "인삼"(3등급)을 **산양삼(山養蔘)**으로 이름을 바꿨습니다.
  - 등급 순서를 개성 인삼(재배, 2) → 개성 홍삼·산양삼(3) → 진상 홍삼(4) → 백두 산삼(5)으로 맞췄습니다.
  - 십전대보탕·경옥고는 개성 인삼(2등급)을 요구하고, 상위 인삼이 대신 쓰일 수 있습니다.
- **대추:** 약초 "대추"를 **건대추(약재)**로 이름을 바꿨습니다. 보은 대추(특산)가 대신 쓰일 수 있습니다.
- **인제 황태 → 춘천 잣:** 황태 덕장은 1950년대 이후라 1861년 배경에 맞지 않습니다. 북관 명태 사슬(명태 → 북어)과 겹치지도 않습니다.
- 기존 **개성 홍삼**은 "개성 인삼 상품"으로 이름을 바꾸고 인삼 사슬에 연결했습니다. 도감에는 "개성 홍삼"으로 나옵니다.

### 1-7. 공용 재료군 · 상위 재료 대체 (기본 '확인')
- **재료군:** 레시피 재료를 `{"group": "grain"}`처럼 적으면 그 군의 품목은 어느 것이든 씁니다.
  - 곡물(말) · 가루 · 수렵육 · 구황 · 섬유 · 대추 · 인삼 · 잣 + 무역품 사슬 17개 = 25개 사슬
- **상위 대체:** 같은 사슬에서 등급이 같거나 높은 품목이 1:1로 대신합니다.
  - 순서: 정확한 품목 → 낮은 등급 → 곧 상할 것
  - 백록·백두 산삼·운철·사리 수정·경면주사는 대체에서 제외합니다.
- **제작 탭**
  - 맨 위에 "상위 재료 대체: 확인/자동/끔" 전환 버튼이 있습니다.
  - 재료 줄에 `대체: 멧돼지 고기 ×1→수렵육`처럼 미리 보여 줍니다.
  - '확인' 모드에서는 **2등급 이상 높은** 재료가 쓰일 때만 확인창이 뜹니다.

## 2. 자유 무역 수익 모델 (설명 · 추천 — 아직 미반영)

**모델:** `python3 tools/trade_sim.py`
- 원산지에서 사서(×0.72) 권역 거리별 배율(1.35 등)로 파는 편도 한 번의 최대 이익을 계산합니다.
- 계산에 넣은 것: 적재량(기본 + 행장 + 탈것 + 동료), 5일 물량, 신선도, 실제 경로 게임 시간(해로 포함)
- 그 이익을 같은 등급 콘텐츠 엽전 수입(경제 시뮬, 균형형)과 비교합니다.

| 신분 | 현재 코드: 편도 이익 | 콘텐츠 수입과 같아지는 편도 수 | 추천안: 편도 이익 | 같아지는 편도 수 |
|---|---|---|---|---|
| R1 | 4,864냥 (제주→전라 남부) | 3.1회 | 276냥 | 55회 |
| R2 | 9,347냥 | 3.5회 | 828냥 | 40회 |
| R3 | 3,229냥 | 19회 | 1,159냥 | 52회 |
| R4 | 54,671냥 (의주 담비 ×160) | **1.9회** | 2,153냥 | 49회 |
| R5 | 110,905냥 | **1.2회** | 15,221냥 | 9회 |

**원인:** 5일 물량을 **장터 노드마다** 따로 셉니다. 그래서 한 권역의 장터 8곳을 돌면 물량이 8배가 됩니다.
- 이 문제는 이번 개편 전부터 있었습니다(기본 4등급 담비 가죽만으로도 발생).
- 판매 쪽 포화도 없어서, 같은 장터에 몇 개를 팔든 값이 그대로입니다.

**추천 (결정해 주시면 반영)**
1. **물량을 권역 단위로 공유합니다.** 원산지 권역 전체가 5일에 20/8/3개를 나눠 씁니다. 이것만으로 표의 "추천안" 수치가 됩니다.
2. **판매 포화를 넣습니다.** 같은 장터에서 같은 품목을 5일 안에 팔 때마다 값이 2%씩 내려가고, 하한은 60%입니다. 한곳에 몰아 파는 것을 막고 여러 곳에 나눠 팔게 됩니다.
3. **목표 비중:** 자유 무역은 콘텐츠 수입을 돕는 보조 수단으로, 같은 등급 수입의 약 10~20%로 둡니다. 추천안에서 R1~R4는 편도 40~55회가 되어야 콘텐츠 수입과 같아지므로 이 범위에 듭니다. R5는 9회로 조금 높은데, 담비 가죽 상품의 물량(8)을 5로 줄이면 맞출 수 있습니다.
4. 반영하면 `economy_sim`에 자유 무역 항목(추천안 기준 상한 × 이용률)을 넣고 신분 기준·엽전 비율을 다시 산출합니다.

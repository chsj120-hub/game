## ① 실행 검증 (P0)
- **문제:** 샌드박스에는 Godot이 없어서 로직·UI 오류가 실제로 얼마나 있는지 모릅니다. 새로 만든 재료 계획·대체·포화 기능은 한 번도 돌려 보지 않았습니다.
- **추천**
  1. 맥 미니에 Godot 4.3+를 설치하고 F5로 실행한 뒤, 출력(Output) 창의 오류를 모아 알려 주세요. 제가 고치겠습니다.
  2. **헤드리스 스모크 테스트** `tests/smoke.gd`를 추가합니다. `godot --headless -s tests/smoke.gd`로 실행하며, 다음을 자동으로 돌립니다.
     - DataDB 로드 → 새 게임 → 이동 10구간 → 상점 구매·매각(포화)
     - 섬 풀기 → 요리 제작(재료군·대체) → 전투 1회 → 저장/불러오기
     - 오류가 나면 exit 1
  3. GitHub Actions에서 공식 Godot 헤드리스 이미지로 스모크 테스트와 Windows/Web 내보내기를 자동으로 합니다(⑦과 함께).

## ② 진행 보정이 계획 콘텐츠 기준 (P0)
`economy_sim`은 `content_plan`(유산 450, 이벤트 24, 무역 퀘스트 30 …)으로 신분 임계와 엽전을 보정합니다. 그런데 실제 데이터는 이만큼 없습니다.

| 항목 | 계획 | 실제 |
|---|---|---|
| 유산 (등급 1~5) | 150/130/95/50/25 = 450 | **3/60/40/29/12 = 144** |
| 유산 명성 합계(추정) | 약 19만 | 약 8.6만 (**45%**) |
| 역사·설화 이벤트 | 24 | 4 |
| 무역 퀘스트 | 30 | 20 |
| 탈것 퀘스트 | 15 | 4 |

- **영향:** R5 임계(73,000)에 닿으려면 지금 데이터의 약 45%를 찾아야 합니다. "1/3이면 엔딩" 규칙에 어긋납니다. 특히 1등급 유산이 3개뿐이라 **초반 명성원이 부족**하고, 1~2등급 구간이 느릴 수 있습니다.
- **추천 (둘 중 하나)**
  - A. `economy_sim --actual`: 실제 데이터 개수로 보정하는 모드를 추가하고, 콘텐츠가 늘 때마다 다시 돌립니다. **지금 테스트용으로 추천합니다.**
  - B. 1등급 유산을 먼저 채웁니다(계획 150 중 3). 향토 유적·비석·정자·장승 등 1등급 후보를 권역당 5~8곳씩 넣습니다.

## ③ 메인 시나리오 (P0)
- 3클래스 × 5장 = 44단계인데, 대사가 "봉서를 받고 남행길에 오른다 (1/2)" 같은 **자리표시 문장**입니다.
- **추천:** 장마다 도입·갈등·선택(2지)·결말 대사와 NPC 이름을 씁니다. 1861년 실제 사건과 엮습니다(철종 말기 삼정 문란, 대동여지도 간행, 동학 창도 1860).
  - 어사: 탐관오리 심판(선택에 따라 명성·엽전 분기)
  - 상인: 개성상인 송방 → 의주 만상 → 대행수
  - 도사: 십승지 봉인
- 분량은 클래스당 약 60~80줄입니다. 원하시면 초안을 쓰겠습니다.

## ④ 세이브 (P0)
- **세이브 버전·마이그레이션:** `save_version`을 넣고, 사라진 id를 자동으로 바꾸는 표를 둡니다(예: `sp_inje_hwangtae` → `sp_chuncheon_jat`, 옛 요리 재료). **이번 개편으로 이미 필요한 상황입니다.**
- **자동 저장 슬롯:** 권역에 들어갈 때와 보스 전에 저장하는 자동 슬롯 1개를 수동 슬롯과 따로 둡니다. 저장은 여전히 주막에서만 되는 고증 규칙은 유지합니다.
- **테스트용 슬롯 3개**와 세이브 내보내기(버그 제보용)

## ⑥ 첫 경험 · 설정 · 사운드 (P1)
- **첫 1시간 안내 퀘스트:** 한양 출발 → 장터 구매·섬 풀기 → 첫 답사 → 첫 전투 → 주막 저장까지. 단계마다 한 줄 도움말을 띄웁니다. 지금은 시스템이 많은데 설명이 없어 테스터가 막히기 쉽습니다.
- **설정 메뉴:** 음량, 글자 크기(1.0/1.2/1.4배), 행군 속도 배율, 자동 섭취, 상위 재료 대체, 전투 속도. 설정은 `user://settings.json`에 따로 저장합니다.
- **사운드:** 지금은 오디오가 전혀 없습니다. 추천 구성은 다음과 같습니다.
  - BGM: 필드(대금·가야금), 도시, 전투, 보스
  - 효과음: 걸음, 엽전, 붓, 북, 징
  - 국악 음원은 공공누리 1유형이나 CC0 자료를 쓰면 상업 이용이 가능합니다.
  - `Assets.gd`에 선택적으로 불러오는 오디오 로더를 넣으면, 파일이 없어도 게임이 동작합니다.
- **조작 안내:** 화면 아래에 단축키(Space 정지 · M 지도 …)를 한 줄로 표시합니다. 키 재설정 기능도 넣습니다.

## ⑦ 배포 · 테스트 운영 (P2)
- **GitHub Actions:** 파이썬 파이프라인 검증 → Godot 헤드리스 스모크 테스트 → Windows exe와 Web 빌드를 결과물(아티팩트)로 올립니다. 필요하면 itch.io 자동 업로드(butler)도 붙입니다.
- **테스트 로그:** 플레이 요약 JSON을 `user://playlog.json`에 남깁니다. 날짜별 신분·엽전·명성, 발견률, 사망, 가장 많이 쓴 메뉴를 기록합니다. 테스터가 보내 주면 `economy_sim` 가정과 실제 플레이를 비교할 수 있습니다.
- **버그 제보 키(F9):** 스크린샷, 최근 로그 100줄, 세이브를 zip 하나로 묶어 저장합니다.
- **데이터 검증을 CI에 연결:** PR마다 validate와 balance를 자동으로 돌립니다.

## ⑧ 편의 기능 (P2)
- **시세 비교(무역 장부):** 갖고 있는 특산물마다 권역 거리별 예상 매도가, 방문한 장터의 포화 상태, 신선도 소진 예상을 보여 줍니다.
- **도감:** 분류 필터(역사/설화/창작/물산), 권역별 완성률, 완성 보상(도 명성 소량)
- **지도:** 노드 유형 필터, 미답사 표시, 진행 중 퀘스트 목적지 강조
- **알림 로그:** 최근 50건을 스크롤로 보는 창(`note()` 기록)
- **배낭:** 정렬(등급·무게·신선도), 상할 물건 경고, "모두 팔기"(포화 반영)

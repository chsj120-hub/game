# 제주 김만덕 편 — 테스트 안내 · 튜토리얼 · 설정

## 시작하기
시작 화면에서 **★ [테스트] 제주 객주 김만덕 편**을 고릅니다.
- 직업: 상인 · 시작 위치: 제주목 제주읍성 · 엽전 500냥
- 상인 기본 지참물에 더해 **백미 한 말 ×3, 장 ×1, 주막 국밥 조리서**를 가지고 시작합니다.
- 메인 시나리오: 「김만덕 — 제주 객주에서 금강산까지」(5장). 본편 클래스 메인 시나리오 대신 진행됩니다.
- **시대 메모:** 김만덕(1739~1812)의 실제 생애(1790년대, 정조 대)를 따릅니다. 본편 배경(1861)과 시대가 달라서, 게임을 시작할 때 기록창에 이 내용을 안내합니다.

## 메인 시나리오 5장 (동선 규칙 준수)
| 장 | 필요 신분 | 무대 | 내용 |
|---|---|---|---|
| 1 객주를 열다 | R1 | 제주목 → 조천 | 관기 명부에서 이름을 빼는 소지 · 첫 거래(정직한 저울 / 웃돈) |
| 2 뭍으로 가는 배 | R2 | 화북진 → 서귀포 | 말총 10을 상선에 싣기 · 잠녀 전복 거래 |
| 3 을묘년 흉년 | R3 | 나주목 → 해남 → 제주목 | 1795년 흉년 · 쌀을 사서(전 재산 / 밑천 남기기) 구휼미 3섬 풀기 |
| 4 바다를 건너는 부름 | R4 | 해남 → 전주 → 공주 | 임금의 소원 물음 · 출륙금지령 예외 · 구휼 장부 셈(주판) |
| 5 일만이천 봉 | R5 | 한양 → 개성 → 철원 → 금강산 구룡폭 | 의녀반수 제수와 정조 알현 · 송상과의 장부법 · 금강산 유람(엔딩) |

제주에서는 이 밖에도 이벤트 3종(설문대할망 · 영등할망 맞이 · 차귀 앞바다 황당선)과 권역 적 2종(제주 도채비 · 영감)을 만납니다.

## 튜토리얼 (화면 오른쪽 위 안내 창)
12단계이며, 조건을 채우면 자동으로 다음 단계로 넘어갑니다. [건너뛰기]로 끌 수 있고, [도움말]에서 다시 시작할 수 있습니다.
1. 화면 구성 (다음)
2. [거점 시설] 열기
3. 장터에서 콩나물 사기
4. 콩나물국밥 요리 (주막)
5. [지도] 열기 (M)
6. 조천으로 이동
7. 이벤트 진행 (김만덕 1장 두 단계)
8. 유산 답사 (조천 방사탑 등)
9. 첫 전투 승리 ([사냥] 가능)
10. 보부상 위탁 수락 (제주목 → 조천 말총)
11. 제주목 주막에서 여정 기록
12. 완료 (다음)

단계 데이터는 `data/23_tutorial.json`의 `steps`에 있습니다. 조건 종류는 ack · counter · visited · at_node · has_item · event_progress입니다. 문구를 바꿀 때는 `tools/content_expand.py`를 고친 뒤 파이프라인을 다시 돌립니다.

## 도움말 (대시보드 [도움말], 시작 화면 ? 도움말)
10개 항목입니다: 이동·지도 / 피로·포만·신선도 / 장터·무역 / 제작·요리·재료 대체 / 유산 답사·보상 3택 / 전투(CTB) / 신분·도 명성·엔딩 / 동료·승급 / 지식 / 저장

## 설정 (대시보드 [설정], 시작 화면 ⚙ 설정)
`user://settings.json`에 게임 저장과 따로 보관됩니다.

| 항목 | 값 | 비고 |
|---|---|---|
| 전체 음량 · 배경 음악 · 효과음 | 0~100% | 오디오 버스 Master/BGM/SFX (음원을 넣으면 적용) |
| 전체 화면 | 켜짐/꺼짐 | |

| 행군 화면 속도 | ×0.75 ~ 1.5 | 화면상 걷는 속도만 바뀜. 게임 시간·피로는 거리 기준이라 그대로 |

## 게임(GDScript) — 노드 311 → 763으로 늘어난 뒤 자주 불리는 경로
| 위치 | 전 | 후 |
|---|---|---|
| `DataDB.nodes_in` (탐색·지도·채집 등 10여 곳) | 호출마다 노드 763개 필터 | 로드 시 권역 색인 → 바로 조회 |
| 지도 모달 `_draw` (매 프레임) | 전체 간선 906개 순회 | 권역 간선 색인만 |
| `GameState.party_knowledge / buff_totals / carry_weight` (매 프레임 이동 속도·메뉴마다) | 매번 장비·동료·행장 전부 재합산 | 입력 상태 해시(엔진 내부 계산)가 같으면 이전 결과 재사용, 바뀌면 자동 재계산 |
| 대시보드·필드·튜토리얼 새로 그리기 | `stats_changed`마다 즉시(한 프레임에 수십 번) | 프레임 끝에 한 번으로 합침 |
| 경로 탐색 `find_path` | 선형 최소 탐색 O(V²) | 이진 힙 O(E log V) |
| 상점 목록 | 품목마다 목록 전체 중복 검사 | 사전으로 중복 확인 |
| 튜토리얼 단계 | 확인할 때마다 전체 필터 | 묶음별 색인 |
| 위탁 짐 무게 | 무역 퀘스트 전체 순회 | 위탁 퀘스트만 미리 추림 |
| 탐색·채집·야영·사냥 발견 | 같은 계산 코드 2벌 | 공통 함수 `_search_params`·`_reveal` 하나로 |
